Padrões de Projeto (GoF)

Conceitos, diferenças entre famílias e demonstrações práticas em C#, Python e JavaScript.

Bruno Carvalho • 05/10/2026

O que são Padrões de Projeto?

Definição

São soluções típicas e reutilizáveis para problemas comuns de design e modelagem orientada a objetos. Não são códigos prontos, mas matrizes de decisão.

Por que usar?

Evitam retrabalho, diminuem o acoplamento, facilitam a manutenção e criam um vocabulário comum entre desenvolvedores da equipe.

Regra de Ouro da GoF

"Programe para interfaces, não para implementações — e prefira sempre composição a herança pura."

Divisão das Três Famílias GoF

1. Criacionais (C#)

Foco: Criação de Objetos

Controlam como as instâncias nascem, evitando dependência direta do operador new.

Exemplos: Singleton, Builder

2. Estruturais (Python)

Foco: Composição e Interfaces

Organizam como classes e objetos se conectam para formar estruturas maiores sem rigidez.

Exemplos: Adapter, Decorator

3. Comportamentais (JS)

Foco: Comunicação e Fluxo

Definem como objetos interagem e delegam tarefas de forma desacoplada.

Exemplos: Strategy, Observer

Singleton • Criacional (C#)

public class Logger
{
    private static Logger? _instancia;
    private static readonly object _padlock = new();

    // Construtor privado: impede "new"
    private Logger() { }

    public static Logger Instancia
    {
        get
        {
            lock (_padlock)
                return _instancia ??= new Logger();
        }
    }

    public void Gravar(string msg) 
        => Console.WriteLine($"[LOG]: {msg}");
}
O que o código faz?

O construtor é private, então ninguém de fora pode instanciar. Todo mundo é forçado a pegar a mesma instância pelo Instancia com segurança a concorrência.

Para explicar em sala

"É a impressora única do escritório: todos mandam documentos para a mesma máquina, você não instala uma impressora física nova para cada computador."

Builder • Criacional (C#)

public class PedidoBuilder
{
    private readonly Pedido _pedido = new();

    public PedidoBuilder ComPao(string p) 
        { _pedido.Pao = p; return this; }

    public PedidoBuilder ComCarne(int q) 
        { _pedido.Carne = q; return this; }

    public Pedido Construir() => _pedido;
}

// Uso direto:
var pedido = new PedidoBuilder()
    .ComPao("Brioche")
    .ComCarne(2)
    .Construir();
O que o código faz?

Cada método configura uma parte do objeto e retorna this. Permite encadear métodos (Fluent API) e evita construtores confusos cheios de parâmetros nulos.

Para explicar em sala

"É montar um lanche no balcão: você vai pedindo ingrediente por ingrediente sob demanda e só recebe o sanduíche fechado no final."

Adapter • Estrutural (Python)

# Sistema legado incompatível
class BancoAntigo:
    def cobrar_centavos(self, centavos: int):
        print(f"Cobrado no legado: {centavos} cents")

# Adaptador intermediário
class AdaptadorPagamento:
    def __init__(self, banco_antigo):
        self.banco = banco_antigo

    def pagar(self, reais: float):
        # Faz a tradução e chama o método antigo
        centavos = int(reais * 100)
        self.banco.cobrar_centavos(centavos)

# Uso:
gateway = AdaptadorPagamento(BancoAntigo())
gateway.pagar(50.0)
O que o código faz?

O nosso código chama pagar(reais). O adaptador recebe a chamada, converte os dados e aciona a função antiga do banco sem precisar alterar o código do banco.

Para explicar em sala

"É um adaptador de tomada: a tomada da parede é antiga, o carregador do notebook é novo. O adaptador no meio faz os dois funcionarem juntos sem quebrar a parede."

Decorator • Estrutural (Python)

# Objeto Base
class Email:
    def enviar(self, msg):
        print(f"[E-mail] {msg}")

# Decorator: embrulha o base e agrega função
class ComZap:
    def __init__(self, wrapped):
        self.wrapped = wrapped

    def enviar(self, msg):
        self.wrapped.enviar(msg)  # Executa o de dentro
        print(f"[WhatsApp] {msg}") # Faz o extra

# Uso empilhado:
notificador = ComZap(Email())
notificador.enviar("Servidor caiu!")
O que o código faz?

A classe ComZap guarda o objeto original dentro dela. Quando você dá enviar(), ela dispara o original primeiro e adiciona o WhatsApp logo em seguida.

Para explicar em sala

"Como uma boneca russa ou vestir um casaco: você não cria uma subclasse nova para cada canal; apenas coloca uma camada a mais por cima do objeto original."

Strategy • Comportamental (JS)

// Algoritmos isolados em funções simples
const freteNormal  = (p) => p * 5.0;
const freteExpresso = (p) => p * 15.0;

class Calculadora {
  constructor(estrategia) {
    this.estrategia = estrategia;
  }
  setEstrategia(nova) {
    this.estrategia = nova;
  }
  calcular(peso) {
    return this.estrategia(peso);
  }
}

// Troca em tempo de execução:
const c = new Calculadora(freteNormal);
c.calcular(10); // 50
c.setEstrategia(freteExpresso);
c.calcular(10); // 150
O que o código faz?

Elimina if/else e switch. As regras de frete viram funções independentes passadas diretamente para a calculadora executar.

Para explicar em sala

"É como escolher como ir para a aula: o objetivo é chegar lá, mas a estratégia muda (carro, ônibus ou bike) dependendo do trânsito ou do dinheiro no bolso."

Observer • Comportamental (JS)

class Canal {
  constructor() {
    this.inscritos = [];
  }
  inscrever(fn) {
    this.inscritos.push(fn);
  }
  notificar(msg) {
    // Dispara para todo mundo da lista
    this.inscritos.forEach(fn => fn(msg));
  }
}

// Assinantes via callback:
const canal = new Canal();
canal.inscrever(msg => console.log(`[Push] ${msg}`));
canal.inscrever(msg => console.log(`[Email] ${msg}`));

canal.notificar("Vídeo novo no ar!");
O que o código faz?

O Canal só guarda uma lista de funções no array. Quando algo acontece, ele roda um forEach chamando todo mundo sem precisar saber quem é quem.

Para explicar em sala

"É o sininho do YouTube: o criador publica o vídeo uma única vez e todos os assinantes recebem o aviso automaticamente."

Quadro Resumo para Apresentação

Padrão Tipo Lang O que resolve na prática?
Singleton Criacional C# Garante só 1 instância viva para recursos compartilhados (log, config).
Builder Criacional C# Constrói objetos complexos passo a passo sem construtores gigantes.
Adapter Estrutural Python Faz sistemas e APIs incompatíveis conversarem sem alterar código antigo.
Decorator Estrutural Python Adiciona novas funções a um objeto como camadas de cebola/roupa.
Strategy Comportamental JS Mata blocos de if/else trocando algoritmos em tempo de execução.
Observer Comportamental JS Notifica automaticamente múltiplos objetos quando um estado muda (1:N).
